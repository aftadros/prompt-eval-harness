The sources don’t name a formal statistical-significance test. Instead, he judges eval deltas by whether they exceed run-to-run noise: on small sets he reruns a prompt several times and checks that the improvement holds rather than relying on one lucky pass [did-the-prompt-change-help--the-average-is-where-a-regression-goes-to-hide]. He also diffs current pass/fail counts against the last run and, when temperature is nonzero, runs each case more than once so a single green run doesn’t hide instability [evals-before-vibes--diffing-against-yesterdays-run].
