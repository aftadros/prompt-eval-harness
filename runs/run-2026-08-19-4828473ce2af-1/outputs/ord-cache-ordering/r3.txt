Order the prompt with **stable material first and volatile material last** so the reusable prefix is as long as possible:

1. Static system prompt  
2. Tool definitions  
3. Retrieved context  
4. User’s question  

This lets the cached prefix cover everything up to the first point where content changes, which can make a long repeated preamble bill at the cheaper cache rate instead of full input cost [llm-cost-at-campus-scale--caching-the-stable-prefix].

Also keep the early parts genuinely stable: if you inject something that varies per request—such as a timestamp or per-user token—near the top, the cacheable prefix shrinks and the savings disappear [llm-cost-at-campus-scale--caching-the-stable-prefix].
