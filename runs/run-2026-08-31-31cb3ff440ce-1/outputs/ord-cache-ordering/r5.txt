Order the prompt with stable material first and volatile material last, so the cacheable prefix is as long as possible:

1. **Static system prompt** — instructions, formatting rules, guardrail preamble  
2. **Tool definitions**  
3. **Retrieved context / passages**  
4. **User’s question**  

The provider can cache a stable prefix of the prompt and charge less for reusing it; the cached prefix covers everything up to the first point where content varies [llm-cost-at-campus-scale--caching-the-stable-prefix].

To keep it working, avoid putting anything that changes per request—such as timestamps or per-user tokens—near the top, because that shrinks the cacheable prefix and can make the savings disappear [llm-cost-at-campus-scale--caching-the-stable-prefix].
