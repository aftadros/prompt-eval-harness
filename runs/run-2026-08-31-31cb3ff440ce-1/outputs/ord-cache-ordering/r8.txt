Order the prompt with stable material first and volatile material last:

1. Static system prompt  
2. Tool definitions  
3. Retrieved context  
4. User’s question  

This lets the cached prefix cover everything up to the first point where content varies, so repeated long preambles can bill at the cache rate rather than full input cost [llm-cost-at-campus-scale--caching-the-stable-prefix].

Also keep the stable parts truly stable: injecting a timestamp or per-user token near the top shrinks the cacheable prefix and can erase the savings [llm-cost-at-campus-scale--caching-the-stable-prefix].
