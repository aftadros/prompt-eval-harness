No—prompt caching lowers the billed cost of cached **input** tokens, not output tokens. Providers charge a fraction of normal input price to reuse a stable prompt prefix, which cuts effective input cost [llm-cost-at-campus-scale--caching-the-stable-prefix]. Output is priced separately and costs several times more than input, so caching does not directly reduce the per-output-token rate or the number of output tokens generated [llm-cost-at-campus-scale--tokens-are-the-row-count].
