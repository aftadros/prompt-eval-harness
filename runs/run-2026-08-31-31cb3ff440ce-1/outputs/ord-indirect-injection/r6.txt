Indirect prompt injection is an attack in which a hostile instruction is hidden inside content that the system retrieves or indexes—such as an onboarding document, wiki comment, or ingested email—and the model then treats it like any other retrieved passage [prompt-injection-in-rag--opening].

It differs from direct prompt injection because the direct kind is typed openly by the user into the chat, such as “ignore your rules,” while indirect injection arrives through fetched content that the user may never see and an administrator may have forgotten was in the index [prompt-injection-in-rag--opening]. In both cases the model receives everything as one stream of tokens, but in indirect injection the instruction is embedded in reference material rather than coming directly from the user [prompt-injection-in-rag--opening] [prompt-injection-is-untrusted-input--the-data-instruction-boundary].
