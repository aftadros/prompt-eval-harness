Indirect prompt injection happens when a malicious instruction is hidden inside content that a RAG system retrieves and includes for the model—such as an indexed document, wiki comment, or ingested email—and the model then reads it with the same trust as any other retrieved passage [prompt-injection-in-rag--opening]. It can work because everything in the context window arrives as one token stream, so a planted instruction inside retrieved text can be treated like any other instruction-shaped text [prompt-injection-in-rag--opening][prompt-injection-is-untrusted-input--the-data-instruction-boundary].

It differs from direct prompt injection in its source: in the direct kind, the user types something like “ignore your rules” into the chat, so it is at least visible where it came from [prompt-injection-in-rag--opening]. In the indirect kind, the hostile sentence rides in on content fetched for the user—often from a source the user never sees and an administrator may have forgotten was even indexed [prompt-injection-in-rag--opening].
