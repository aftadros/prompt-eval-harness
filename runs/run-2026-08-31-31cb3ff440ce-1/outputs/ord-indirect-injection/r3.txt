Indirect prompt injection is a malicious instruction hidden in content that a RAG system retrieves or indexes—such as an onboarding doc, wiki comment, or ingested email—that the model reads with the same trust it gives other retrieved passages [prompt-injection-in-rag--opening].

It differs from direct prompt injection because the direct kind comes openly from the user typing something like “ignore your rules” into the chat. The indirect kind instead rides in on fetched reference material, often from a source the user never sees and an administrator may have forgotten was even in the index [prompt-injection-in-rag--opening]. Both exploit the fact that LLMs receive instructions and data as one undifferentiated token stream rather than over separate channels [prompt-injection-is-untrusted-input--the-data-instruction-boundary][prompt-injection-in-rag--opening].
