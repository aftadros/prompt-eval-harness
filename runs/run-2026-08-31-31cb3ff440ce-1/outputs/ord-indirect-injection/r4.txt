Indirect prompt injection is when a hostile instruction is embedded in content that the system retrieves or indexes for a user—such as an onboarding doc, wiki comment, or ingested email—and the model reads it as part of the retrieved context [prompt-injection-in-rag--opening]. It differs from direct prompt injection because the malicious text does not come from what the user types into the chat; instead, it “rides in” on fetched material from a source the user never sees and an administrator may have forgotten was indexed [prompt-injection-in-rag--opening]. The direct kind is more transparent: the user explicitly enters something like “ignore your rules,” so the attack’s origin is obvious [prompt-injection-in-rag--opening].
