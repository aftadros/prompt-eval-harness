For every model call, log:

- Request ID  
- Model and version  
- Input token count  
- Output token count  
- Latency split into time-to-first-token and total latency  
- Which retry attempt it was  
- Whether the circuit breaker was open  
- Which path served the response: model, fallback, or kill switch  

Also avoid logging secrets, and treat prompts and user content as sensitive because they often are. [llm-api-from-php-in-production--log-enough-to-reconstruct-one-call]
