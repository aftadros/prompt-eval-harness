On every model call, you should log enough to reconstruct the call:

- A request ID  
- The model and version used  
- Input and output token counts  
- Latency, split into time-to-first-token and total latency  
- Which retry attempt it was  
- Whether the circuit breaker was open  
- Which path served the response: the model, a fallback, or the kill switch  

You should not log secrets, and you should treat prompts and user content as sensitive [llm-api-from-php-in-production--log-enough-to-reconstruct-one-call].
