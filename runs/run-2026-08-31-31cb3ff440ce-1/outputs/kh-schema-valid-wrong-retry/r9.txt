A response that is schema-valid but has the wrong enum value for the input is “schema-valid-but-wrong,” so run your own code-side check and, if it fails, send the specific failure back into the prompt (e.g., “you returned X; choose from this list”) [structured-outputs--retry-on-schema-mismatch].

Keep it bounded: give the model one repair attempt with the error attached, then fall back rather than keep hammering it [llm-json-in-php--one-repair-attempt].
