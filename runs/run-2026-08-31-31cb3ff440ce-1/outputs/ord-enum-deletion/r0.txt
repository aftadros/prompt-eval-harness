Putting an `enum` in the schema turned a free-text classification problem into a fixed-choice one: instead of the model returning variations like “Billing”, “billing issue”, or even a sentence, it had to pick one of the four allowed values [structured-outputs--schema-constrained-generation]. That removed the need for the author’s lowercase-and-fuzzy-match step that collapsed those free-form answers into buckets, and also eliminated the test file covering that mapping logic [structured-outputs--schema-constrained-generation].
