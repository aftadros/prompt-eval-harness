Putting an `enum` in the schema made the model’s output structurally constrained to one of the allowed values, so free-text variants like “Billing,” “BILLING,” or “this looks like a billing question to me” could no longer appear [structured-outputs--schema-constrained-generation]. That removed the need for the lowercase-and-fuzzy-match step that had collapsed those variants into the four buckets, and it also eliminated the test file that covered that mapping code [structured-outputs--schema-constrained-generation].
