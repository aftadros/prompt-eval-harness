Putting an `enum` in the schema deleted code because it removed the need to normalize free-text category output. Previously, the model could return variants like `"Billing"`, `"billing issue"`, or even a full sentence, so the author had a lowercase-and-fuzzy-match step to collapse those into four allowed buckets. With the enum, only those four values are valid outputs, so the mapping/normalization code—and its test file—were no longer needed [structured-outputs--schema-constrained-generation].
