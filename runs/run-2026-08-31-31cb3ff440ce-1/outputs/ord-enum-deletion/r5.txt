Putting an `enum` in the schema deleted code by removing the need to clean up free-text category output afterward. Previously, the model could return variants like `"Billing"`, `"billing issue"`, or `"this looks like a billing question to me"`, so the author needed a lowercase-and-fuzzy-match step to collapse those into four buckets. With the enum in the schema, generation is constrained to one of the four allowed values, so that mapping step—and its test file—disappeared [structured-outputs--schema-constrained-generation].
