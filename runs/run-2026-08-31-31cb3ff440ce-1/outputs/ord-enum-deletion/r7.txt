Putting an `enum` in the schema made the provider’s constrained decoder only allow one of the declared category strings, so the model could no longer return variants like `"Billing"`, `"billing issue"`, or free-text explanations [structured-outputs--schema-constrained-generation]. That removed the need for the author’s lowercase-and-fuzzy-match step that collapsed those variations into the four buckets — and with it, the mapping code and its test file [structured-outputs--schema-constrained-generation].
