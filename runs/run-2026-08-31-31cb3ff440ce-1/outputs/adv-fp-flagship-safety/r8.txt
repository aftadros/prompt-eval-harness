They describe routing by query shape and risk: clean factual lookups can use the cheap tier, while multi-document, conflicting-source, or weak-retrieval questions go to the more capable “flagship”/smart model [llm-cost-at-campus-scale--which-model-gets-the-question]. Escalation means starting cheaply and retrying on the smart model only if a confidence check or guardrail flags the answer as thin [llm-cost-at-campus-scale--which-model-gets-the-question].

For safety layers, the documents say each check has a cost and should be chosen by risk—some run every request, others on a sample—and that you shouldn’t spend a heavy verification pass protecting a short answer unless the risk warrants it [llm-cost-at-campus-scale--guardrails-have-a-cost-too]. So they support using stronger models or checks where scrutiny or risk justifies them, not a blanket rule for all safety-critical answers.
