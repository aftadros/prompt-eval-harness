Not universally “always.” Refusal is a tradeoff: if it is tuned too eagerly the assistant hallucinates, and if it is tuned too cautiously it refuses to answer questions it could have answered [rag-over-internal-docs--the-honest-i-dont-know]. For documentation that people use to make decisions, the recommendation is to “lean toward refusing when unsure,” because a confident wrong answer can be acted on while an admitted miss only sends someone to a human [rag-over-internal-docs--the-honest-i-dont-know].
