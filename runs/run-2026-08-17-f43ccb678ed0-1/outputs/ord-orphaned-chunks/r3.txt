An **orphaned chunk** is a fragment of a document that was removed or rewritten earlier but is still sitting in the index, where it can “win retrieval for some unlucky query” [rag-over-internal-docs--freshness-is-an-indexing-problem].

You should care because orphaned chunks are described as a classic production failure: they can make an assistant return stale guidance, and a pipeline that only ever adds will keep them forever unless old vectors are deleted or cleaned up by reconciliation [rag-over-internal-docs--freshness-is-an-indexing-problem].
