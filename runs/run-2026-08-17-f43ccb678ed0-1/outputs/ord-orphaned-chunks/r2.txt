An **orphaned chunk** is a fragment of a document that was removed or rewritten earlier but remains in the index, and it can still win retrieval for some query [rag-over-internal-docs--freshness-is-an-indexing-problem]. You should care because it causes the assistant to return stale guidance as if it were current; a pipeline that only adds chunks will keep those orphans around forever [rag-over-internal-docs--freshness-is-an-indexing-problem].
