Putting an `enum` in the schema deleted code by removing the need for post-processing cleanup. Before, the model could return variations like “Billing,” “billing issue,” or “this looks like a billing question to me,” so the author had to lowercase and fuzzy-match the result into one of four buckets. With the enum constraint, the output is forced to be one of the allowed values, so that mapping step was gone — along with the test file covering it [structured-outputs--schema-constrained-generation].
