Putting an `enum` in the schema deleted code by removing the need to normalize free-text model output. Before, the model could return variants like “Billing”, “billing issue”, or “this looks like a billing question to me,” so you needed a lowercase-and-fuzzy-match step to collapse them into one of four buckets [structured-outputs--schema-constrained-generation]. With the enum in the schema, those are the only allowed values, so the mapping step was gone — along with its test file [structured-outputs--schema-constrained-generation].
