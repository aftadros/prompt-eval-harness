Putting an `enum` in the schema let the constrained decoder restrict the model’s output to exactly four allowed values, so it could no longer return variations like `"Billing"`, `"billing issue"`, or a full sentence. That removed the need for the author’s lowercase-and-fuzzy-matching step that collapsed free-text responses into the four buckets—and also deleted the test file covering that mapping logic [structured-outputs--schema-constrained-generation].
