You should log, for every model call [llm-api-from-php-in-production--log-enough-to-reconstruct-one-call]:

- A request ID  
- The model and version  
- Input and output token counts  
- Latency split into:
  - Time to first token  
  - Total latency  
- Which retry attempt it was  
- Whether the circuit breaker was open  
- Which path served the response:
  - Model  
  - Fallback  
  - Kill switch  

You should also avoid logging secrets and treat prompts and user content as sensitive [llm-api-from-php-in-production--log-enough-to-reconstruct-one-call].
