Order the prompt so **stable content comes first and volatile content comes last**:

1. **Static system prompt**
2. **Tool definitions**
3. **Retrieved context**
4. **User question**

This lets the provider cache “everything up to the first point where content varies,” so repeated preambles bill at the lower cache rate instead of full input cost [llm-cost-at-campus-scale--caching-the-stable-prefix].
