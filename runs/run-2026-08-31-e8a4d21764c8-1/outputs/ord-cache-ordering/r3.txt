Order the prompt so **stable material comes first and volatile content comes last**. Use this order:

1. **Static system prompt**  
2. **Tool definitions**  
3. **Retrieved context**  
4. **The user’s question**  

This lets the cached prefix cover everything up to the first point where the prompt varies, so repeated preambles bill at the lower cache rate instead of full input cost [llm-cost-at-campus-scale--caching-the-stable-prefix].

To keep it working, avoid putting frequently changing values—such as timestamps or per-user tokens—near the top of the prompt. If you do that, the cacheable prefix can shrink to nothing and the savings disappear [llm-cost-at-campus-scale--caching-the-stable-prefix].
