Indirect prompt injection occurs when a hostile instruction is planted inside content that the retrieval system fetches and gives to the model—such as an onboarding document, a pasted wiki comment, or an ingested email—and the model treats it like any other retrieved passage [prompt-injection-in-rag--opening]. It differs from direct prompt injection because the direct kind comes openly from the user typing something like “ignore your rules” into the chat, while the indirect kind rides in on fetched reference material from a source the user never sees and an admin may have forgotten was indexed [prompt-injection-in-rag--opening]. In both cases, system prompts, user input, and retrieved text arrive as one token stream with no guaranteed boundary between data and instructions, so instruction-shaped text inside a retrieved chunk can be followed by the model [prompt-injection-in-rag--opening; prompt-injection-is-untrusted-input--the-data-instruction-boundary].
