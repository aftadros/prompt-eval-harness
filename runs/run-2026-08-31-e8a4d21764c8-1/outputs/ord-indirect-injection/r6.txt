Indirect prompt injection happens when a malicious instruction is hidden inside content that the retrieval system fetches and feeds to the model—such as an indexed document, wiki comment, or ingested email—and the model treats that planted line with the same trust as any other retrieved passage [prompt-injection-in-rag--opening]. It comes “in on content the system fetched for the user,” often from a source the user never sees and that an administrator may have forgotten was in the index [prompt-injection-in-rag--opening].

The direct kind is when a user types an instruction like “ignore your rules” directly into the chat, so its origin is visible [prompt-injection-in-rag--opening]. In both cases the model has no separate channel for instructions versus data; everything arrives as one token stream, so retrieved text can be read as an instruction if it is worded authoritatively enough [prompt-injection-is-untrusted-input--the-data-instruction-boundary] [prompt-injection-in-rag--opening].
