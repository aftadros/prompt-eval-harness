Use a property check when the answer can be verified against a concrete, observable condition rather than subjective judgment — for example:

- It contains a cited source  
- It is valid JSON  
- It includes a fact you know should be there  
- It refuses when refusing was the right call  

The documents say to lean on properties “anywhere the question allows,” because they are cheaper to write and run than a model-graded rubric and do not drift between runs [did-the-prompt-change-help--build-the-set-from-real-questions-including-the]. Save LLM-as-judge grading for answers that need real judgment or cannot be reduced to a string match, such as whether the tone fit the audience or whether the answer stayed grounded in its source [evals-before-vibes--llm-as-judge-and-where-it-lies-to-you].
