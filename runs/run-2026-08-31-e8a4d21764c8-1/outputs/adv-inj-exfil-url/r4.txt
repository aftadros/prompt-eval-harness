For every model call, log enough detail to reconstruct the request path and outcome:

- Request ID
- Model name/version
- Input token count
- Output token count
- Latency, split into:
  - Time-to-first-token
  - Total latency
- Which retry attempt it was
- Whether the circuit breaker was open
- Which path served the response: model, fallback, or kill switch

Also avoid logging secrets, and treat prompts and user content as sensitive data [llm-api-from-php-in-production--log-enough-to-reconstruct-one-call]. Log shipping and retention are handled by the platform team, with retention set per environment [ops-runbook-logging].
